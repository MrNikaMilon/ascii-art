Аркада, в которой ты играешь за муху. В терминальной версии уворачивайся от стрел и продержись как можно дольше. В браузере чередуются кооперативный бой с боссом и соревнование на выживание.

В примерах используется Python 3.13. Все команды выполняются из корня проекта.

## Терминальная игра

```sh
python3.13 fly_game.py
```

Стрелки вверх и вниз или `W` и `S` — движение. `P` — пауза, `Q` — выход, `R` — перезапуск после проигрыша.

## Браузерный мультиплеер

```sh
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r multiplayer/requirements.txt
python -m uvicorn --app-dir multiplayer app:app
```

Открой [игру в браузере](http://127.0.0.1:8000), введи ник и создай комнату. Хозяин комнаты запускает матч. Стрелки или `WASD` — движение, пробел — выстрел в режиме боя с боссом.

После начального отсчёта комната переключает режимы каждые 60 секунд. Сначала игроки вместе сражаются с Тимуром. Затем в Last Fly Standing побеждает тот, кто первым выиграет три раунда. Если в раунде участвует одна муха, он проходит как тренировка без начисления побед.

При переключении арена ставится на паузу. Позиции мух, снаряды, здоровье босса, счёт и таймеры сохраняются в комнате и возобновляются при возврате в режим. После победы хозяин может перезапустить текущий режим из экрана результатов.

Для игры по локальной сети добавь `--host 0.0.0.0` к команде запуска, открой игру по IP-адресу компьютера с сервером и поделись ссылкой на комнату.

## Тесты

